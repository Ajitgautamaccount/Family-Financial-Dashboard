Logs & Guidance

  • Dry run writes payload JSON files to the server logs/ folder: payload_<UploadKey>.json
  • API responses are saved as response_<UploadKey>.txt. Errors are saved as error_<UploadKey>.txt
  • Use the result page links to download payloads and responses after processing.

Quick checklist before running

  1. Vendor, material, plant, cost center values must exist in the target tenant.
  2. Run in a test/non-production tenant first.
  3. Start the server with python web_app.py and keep the console open for logs.
