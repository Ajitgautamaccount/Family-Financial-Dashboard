PATCH NOTES — proxy.js v2
===========================

What changed
------------
1. The proxy now CATCHES the Kite redirect.
   When Zerodha sends the browser back to
       http://localhost:3001/?request_token=XXX&status=success
   the proxy:
     - Saves the request_token in memory (valid 2 minutes)
     - Shows a nice green "Login successful" page with a Copy button
   No more confusing "Unknown endpoint" JSON.

2. New endpoint:  GET /last-token
   Returns {"token": "...", "age_ms": ...} if a token was captured
   in the last 2 minutes. The dashboard can poll this to auto-fill
   the Login dialog.

3. New endpoint:  GET /clear-token
   Wipes the stored token after the dashboard consumes it.

How to apply
------------
1. Stop the old proxy (Ctrl+C in the terminal window).
2. Replace your existing  zerodha-dashboard/proxy.js  with this one.
3. Start it again:   node proxy.js
4. In your Kite Connect app settings (developers.kite.trade/apps),
   make sure REDIRECT URL is exactly:
       http://localhost:3001
   (no trailing slash, no path)
5. Login again from the dashboard — you'll see the green success page.

Nothing else needs to change in index.html. The old manual
copy-paste flow still works exactly as before.
