Your Monthly Routine
M

1st Monday — Deploy (15 min)

Check VIX. Calculate strikes using Strike Setup tab. Place 4 orders on Zerodha. Set price alerts. Done.

W

Every Tue & Thu — Monitor (5 min)

Run Weekly Checklist. Check if Nifty is safe. Check VIX. If both OK — close the app and go back to work.

E

Expiry Thursday — Exit or Auto-expire

If position has 50%+ profit already, exit early. Otherwise let it expire. Don't touch on expiry day itself (volatile last hour).
